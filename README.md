# Dental Clinic Management System

A comprehensive dental clinic management system with a Spring Boot backend and React frontend.

## Project Structure

- **dentalClinicApp/** - Spring Boot backend application
- **dentalClinicUI/** - React frontend application

## Quick Start

### Backend (Spring Boot)
```bash
cd dentalClinicApp
mvn spring-boot:run
```

### Frontend (React)
```bash
cd dentalClinicUI
npm install
npm run dev
```

## Documentation

- [Backend README](dentalClinicApp/README.md)
- [Frontend README](dentalClinicUI/README.md)

## Features

- Patient management
- Appointment scheduling
- Treatment records
- Prescription management
- Matrix chat integration
- Multi-language support (English/Arabic)

## Technology Stack

### Backend
- Java Spring Boot
- PostgreSQL
- Maven
- Matrix Protocol

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
